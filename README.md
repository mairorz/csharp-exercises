# 📌 C# | ASP.NET Core 9 Web API  

Este repositorio reúne el trabajo y las prácticas realizadas durante mi periodo de formación y prácticas profesionales, enfocadas en **C#** y **ASP.NET Core 9 (Web API)**.  

## 🚀 Tecnologías
- C#
- ASP.NET Core 9
- Entity Framework Core
- Swagger / OpenAPI
- MySQL

## 🎯 Objetivo
El objetivo principal de este proyecto es **demostrar el avance en el aprendizaje hasta llegar a la construcción de una API completa**, aplicando buenas prácticas de desarrollo y las herramientas más utilizadas en la industria.

## 🌿 Ramas del repositorio
El contenido se encuentra organizado en diferentes ramas, de acuerdo al enfoque de aprendizaje:  

- **`csharp`** → Incluye ejemplos, ejercicios y conceptos sencillos fundamentales del lenguaje **C#**.  
- **`api`** → Desarrolla una aplicación en **ASP.NET Core 9 Web API**, aplicando el patrón **MVC**, conceptos de **arquitectura limpia** y buenas prácticas de desarrollo, con el objetivo de construir una API completa, documentada y funcional.

## 📝 Nota
Este repositorio no corresponde a un proyecto productivo, sino a un espacio de **aprendizaje y práctica**.
