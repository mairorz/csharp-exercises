# C# Web API - ASP.NET Core 9

Este repositorio contiene el trabajo y las prácticas realizadas durante mi periodo de formación y prácticas profesionales, enfocadas en **C#** y **ASP.NET Core 9 (Web API)**.  

## 🚀 Tecnologías
- C# 12
- ASP.NET Core 9
- Entity Framework Core
- Swagger / OpenAPI
- MySQL

## 📚 Objetivo
El propósito de este repositorio es dejar evidencia del aprendizaje y ejercicios realizados, incluyendo:
- Creación de controladores y rutas.
- Uso de DTOs.
- CRUD con Entity Framework.
- Documentación con Swagger.

## 📝 Nota
Este repositorio no corresponde a un proyecto productivo, sino a un espacio de **aprendizaje y práctica**.
